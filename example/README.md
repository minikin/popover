# Popover example

Nine buttons across the screen, each opening a 200 by 400 popover with
`showPopover`. The corners show the flip to the opposite side. On a short
screen, such as a phone in landscape or a small macOS window, the middle row
shows the body shrinking to fit, or on macOS moving to the side. Run it from
this directory:

```bash
flutter run
```

`integration_test/popover_test.dart` opens every button, taps an item and
rotates the device. CONTRIBUTING.md in the repository root shows how to run it.
