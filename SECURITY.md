# Security policy

## Reporting a vulnerability

Report it privately: open the Security tab of this repository and use "Report
a vulnerability". Issues are disabled, so do not post it in a pull request or
anywhere public.

Include what the vulnerability is and what it affects, steps to reproduce it,
and a fix if you have one.

One maintainer looks after popover in spare time. There is no response-time
commitment.

## Supported versions

Fixes go into the latest release only.
